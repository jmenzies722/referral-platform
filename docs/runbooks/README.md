# Runbooks

One runbook per alert. Template:

```
# <Alert name>
What it means:  <the symptom, in user terms>
Impact:         <who is affected and how badly>
Dashboards:     <links>
Diagnose:       1. … 2. … (commands, queries)
Mitigate:       <safe first actions: rollback, scale, failover>
Escalate:       <when, and to whom>
Last reviewed:  <date / owner>
```
